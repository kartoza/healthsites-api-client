# Installation

## Using pip

```bash
pip install healthsites-api-client
```

## Using Nix

If you use Nix, enter the development shell:

```bash
nix develop
```

## From source

```bash
git clone https://github.com/kartoza/healthsites-api-client.git
cd healthsites-api-client
pip install -e ".[dev]"
```

## Requirements

- Python 3.10 or higher
- httpx
